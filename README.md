# 轨迹模型（GMM）入门与 Shiny 操作指南

面向**医学生与临床研究者**的轨迹模型（Growth Mixture Model, GMM）入门教材，同时是一份可落地的 Shiny 图形界面操作手册，配套「轨迹分析工具 v2.1.0（轨迹单独版）」使用。

本教程从**临床问题**出发，先讲清轨迹模型"是什么、为什么"，再讲透界面每个参数背后的**统计学原理**，最后用一个**完整实战案例**走通全流程。

## 安装与启动

本工具以 R 包 `Ztraje` 的形式分发，安装后在 R 中运行 `run_app()` 即可打开操作界面：

```r
install.packages("remotes")
remotes::install_github("Zstats/zstatsManage")
zstatsManage::installFromOSS("Ztraje")
library(Ztraje)
run_app()
```

> 详见教程 [第零章 安装与启动](./轨迹模型GMM入门与Shiny操作指南.md#第零章-安装与启动)。

## 覆盖的核心知识点

- 轨迹模型与混合效应模型、聚类分析的区别
- GBTM / LCGA / GMM 三种模型的关系与选择
- 模型公式：固定效应 + 随机效应 + 潜类别
- 多项式时间函数（线性 / 二次 / 三次）的选择原则
- 极大似然估计与 EM 算法直观理解
- **起始值与局部最优**问题，及"单类别模型法 / 网格搜索法"两种策略
- 后验概率与个体归类
- 模型选择指标：AIC、BIC、SABIC、Entropy、LMR 检验、AVE、类别比例
- 组数决策的"五看"准则
- 收敛判读与常见报错处理
- 时间尺度变换（年份重赋值）的数值稳定性原理
- 长格式 / 宽格式数据整形与后续分析衔接
