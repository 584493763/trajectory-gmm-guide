# 教程一 · 轨迹模型（GMM）入门与 Shiny 操作指南

轨迹模型（Growth Mixture Model, GMM）用于分析**纵向随访数据**，识别随时间变化的不同人群轨迹，配套「轨迹分析工具 v2.1.0（轨迹单独版）」使用。

## 适合谁读

- 临床医学、公共卫生、护理、康复等专业的研究生与科研人员；
- 需要分析纵向随访数据（多次测量）但不想被公式劝退的研究者；
- 使用轨迹模型 / 潜类别增长模型 / 增长混合模型做课题、写论文的同学；
- 想快速上手轨迹分析 Shiny 工具的人。

## 内容结构

| --- | --- |

| 第二章 统计学理论基础 | 模型公式、固定/随机效应、多项式阶次、极大似然与 EM、起始值与局部最优、后验概率、AIC/BIC/SABIC/Entropy/LMR/AVE 详解、组数决策"五看"准则、时间尺度变换 |
| 第三章 数据准备理论 | 长格式数据要求、ID/时间/轨迹三类变量、缺失值处理、样本量与设计建议、检查清单 |

## 安装与启动

本工具以 R 包 `Ztraje` 的形式分发，安装后在 R 中运行 `run_app()` 即可打开操作界面：

```r
install.packages("remotes")
remotes::install_github("Zstats/zstatsManage")
zstatsManage::installFromOSS("Ztraje")
library(Ztraje)
run_app()
```

> 详见教程 [第零章 安装与启动](./轨迹模型GMM入门与Shiny操作指南.md#第零章-安装与启动)。

## 覆盖的核心知识点

- 轨迹模型与混合效应模型、聚类分析的区别
- GBTM / LCGA / GMM 三种模型的关系与选择
- 模型公式：固定效应 + 随机效应 + 潜类别
- 多项式时间函数（线性 / 二次 / 三次）的选择原则
- **起始值与局部最优**问题，及"单类别模型法 / 网格搜索法"两种策略
- 后验概率与个体归类；模型选择指标（AIC、BIC、SABIC、Entropy、LMR、AVE）
- 组数决策的"五看"准则；收敛判读；时间尺度变换的数值稳定性原理

# 教程二 · K-means 聚类分析入门与平台操作指南

K-means 聚类分析用于**横截面数据**，把个体按"相似程度"分成若干可命名的亚型，配套「**风暴统计平台 · K-means 聚类分析模块 v4.0.5**」使用。

## 适合谁读

- 想给人群做**表型分型 / 风险分层**的临床与公卫研究者；
- 需要把"杂乱的多指标"归纳成几个可解释亚群的同学；
- 想快速上手风暴统计平台 K-means 模块的人；
- 想搞清楚"聚类数 K 到底怎么定"的人。

## 内容结构

| 章节 | 内容 |
| --- | --- |
| 第零章 平台入口与数据准备 | 平台地址与登录、数据导入格式要求、聚类分析对数据的特别要求 |
| 第一章 认识聚类分析与 K-means | 无监督学习直觉、临床场景、与层次聚类/GMM/LCA 的对比、与轨迹模型的区别 |
| 第二章 K-means 统计学理论基础 | 目标函数与算法四步、距离度量、标准化的必要性、四种起始值方法、**确定 K 的 5 个指标**（簇内平方和/轮廓系数/AIC/BIC/调整 R²）、聚类质量评价、常见陷阱 |
| 第三章 平台 K-means 模块操作指南 | 逐页逐控件讲解：最优聚类选择、聚类分析、聚类可视化、分组批量差异性分析、定量数据批量差异性分析、数据下载 |

## 覆盖的核心知识点

- 聚类分析与轨迹模型的适用场景差异
- K-means 目标函数（最小化簇内平方和）与"分配—更新"迭代
- 为什么必须标准化；不标准化会有什么后果
- 四种起始值方法（kmeans++ / random / quantile_init / optimal_init）与实际稳定性差异
- **确定聚类数 K 的五个指标**及其判读方向、优缺点与"打架"时怎么办
- 轮廓系数的阈值解读；各簇轮廓系数、样本量、稳定性检验
- 一键生成论文用三线表（分组差异性分析 / 定量数据批量差异性分析）
